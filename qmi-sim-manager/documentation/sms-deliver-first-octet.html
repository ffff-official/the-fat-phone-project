First octet of the SMS-DELIVER PDU

The first octet of the SMS-DELIVER PDU has the following layout:

Bit no76543210
NameTP-RPTP-UDHITP-SRI(unused)(unused)TP-MMSTP-MTITP-MTI

where the fields have the following meaning:

NameMeaning
TP-RPReply path. Parameter indicating that reply path exists.
TP-UDHIUser data header indicator. This bit is set to 1 if the User Data field starts with a header
TP-SRIStatus report indication. This bit is set to 1 if a status report is going to be returned to the SME
TP-MMSMore messages to send. This bit is set to 0 if there are more messages to send
TP-MTIMessage type indicator. Bits no 1 and 0 are both set to 0 to indicate that this PDU is an SMS-DELIVER

Example

A first octet of "04" (hex) has the following meaning:

Bit no76543210
NameTP-RPTP-UDHITP-SRI(unused)(unused)TP-MMSTP-MTITP-MTI
Value00000100
